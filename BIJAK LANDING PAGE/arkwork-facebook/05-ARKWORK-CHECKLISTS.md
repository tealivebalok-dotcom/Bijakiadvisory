**Comment keyword:** FORMULA

**The 3 Documents:**

**1. Form A (SSM) — Common Mistakes:**
- [ ] Notarised IC copies (all directors/shareholders)
- [ ] Address matches exactly — no abbreviations
- [ ] Signature not witnessed correctly (must be by advocate/solicitor OR commissioner of oaths)
- [ ] Date filled in (old forms get auto-rejected)

**2. Company Name Search Results:**
- [ ] Submit within 30 days of name search (name search expires)
- [ ] All 3 name choices in priority order
- [ ] Business activity codes match your intended operations (MIDA codes)
- [ ] If using similar name to existing company — written consent letter uploaded

**3. Registered Address Proof:**
- [ ] Utility bill (max 3 months old)
- [ ] Rental agreement OR SSM-preferred format
- [ ] If using home address —同意書 (consent letter) from owner

**Pro tip:** Submit ALL documents in ONE submission. Partial submissions = partial processing = weeks of delay.

## CHECKLIST 6 — "MyCoID Step-by-Step"
**Comment keyword:** MYCOID
**Post:** Post 3 (MyCoID Confusion)

**MyCoID Registration Walkthrough:**

**Step 1 — Create Account:**
1. Go to: https://ezbiz.ssm.com.my/
2. Click "Pendaftaran Akaun" (Account Registration)
3. Select "Ahli Profesional" OR "Individu"
4. Fill: IC number, email, phone
5. Verify email + phone OTP

**Step 2 — Login:**
1. Use IC number as username
2. Password from registration email
3. First login: Change password immediately

**Step 3 — Name Search:**
1. Click "Carian Nama" (Name Search)
2. Key in 3 proposed names
3. Select business activities (BE CAREFUL — wrong codes = MIDA rejection later)
4. Pay RM50 per name online
5. Wait 1-3 days for SSM approval (or same day at SSM counter)

**Step 4 — Register Company:**
1. After name approved: Click "Pendaftaran Syarikat" (Company Registration)
2. Fill all director/shareholder details EXACTLY as per IC
3. Upload required documents (IC copies, address proof, consent letter)
4. Pay registration fee online (RM1,000-RM1,200)
5. Submit

**COMMON MISTAKES THAT FREEZE THE SCREEN:**
- Wrong IC number format
- Wrong activity codes
- Address with abbreviations SSM doesn't accept
- Documents too large (max 2MB each)
- Using Internet Explorer (use Chrome instead)

## CHECKLIST 7 — "Employment Pass vs Business Visa"
**Comment keyword:** VISA
**Post:** Post 16 (Employment Pass vs Business Visa)

**Types of Passes for Foreigners in Malaysia:**

**1. Employment Pass (EP) — Category 1:**
- For skilled workers, professionals, managers
- Valid: 2-5 years (renewable)
- Can work FULL TIME for your company
- Must earn RM10,000+/month (typical requirement)
- Requires: Job offer from Malaysian company, qualifications assessed by ESD

**2. Employment Pass (EP) — Category 2:**
- Mid-level skilled workers
- Valid: 2 years
- Salary requirement: RM5,000-RM9,999/month

**3. Dependant Pass:**
- For spouse and children of EP holder
- CANNOT work legally
- Can open bank accounts
- Can drive (with international license)

**4. Business Visa (without Employment Pass):**
- 30-day entry visa (not a work pass)
- CANNOT work
- CANNOT register a company as director
- CAN be shareholder only

**5. MM2H (Malaysia My Second Home):**
- Long-term residence visa (10 years renewable)
- Does NOT automatically allow work
- Separate work pass required if you want to work

**DANGER:** Operating on wrong pass type = blacklisted from Malaysia + deportation

**RECOMMENDED ORDER:**
1. Get employment pass first (you or your partner)
2. THEN register company with you as director
3. THEN apply for dependant pass for family
